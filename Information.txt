 STANDARD RUN CONDITIONS:
	1. Each version had 20, consecutive trials, comprising of the same dataset (same 100,000 puzzles across all trials of all versions)
	2. The program is fixed to run on CPU 4 of the Intel i7-13700H (A performance core)
	3. The CPU frequency policy of CPU 4 was constrained to 2.1GHz (arbitrarily chosen, but is a safe frequency to avoid thermal throttling, or worse...I can't afford a new laptop)
	4. Run using the command: ./run.sh ./vX/solvervX
